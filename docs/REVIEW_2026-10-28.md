## Verdict

**The foundation is solid and the docs are honest:**
- The truth rule holds: model output never changes facts, lie flags, tells, refutations, objections or verdicts.
- No secret has ever been committed: every historical scene has blank token fields.
- The engine is pure, deterministic and replayable.

**The main problems:**
- several rule bugs that let a player win without reasoning;
- lie stance leaking into the AI prompt;
- a validator that misses common confession wording;
- live-answer latency (one sample: 8.97 s against the 6.5 s limit);
- the Lens side is still a shell (no production interrogation path), and the hero case and the Preview room use different coordinates.

**Status corrections** (update PROGRESS and the handoff):
- The test suite is **green: 252/252, exit 0, about 70 s**.
- The async case-fuzz fix is **verified**: the old synchronous version reproduces the worker RPC timeout; the new one doesn't.
- The Lens log shows the final tree **compiled at 22:06:08** and Preview started cleanly four times afterwards.
- `tsc` reports 2 type errors in `Tooling/tests/ai/pipeline.test.ts:38` (vitest doesn't type-check).

## Scope (needs Wadood's decision)

The Lens/repo reviewer estimates about 70–100 focused hours for one complete, polished case in Preview (room binding, live interrogation, tells, objection, suggestion sweep, accusation and reenactment, opening, fallback ladder, staging), plus device checks and video. **Recommendation:** build one complete case end to end first: the "never cut" list (interrogation with tells, Spatial Objection, suggestion sweep, accusation and reenactment, opening). Then the should tier in order. Clue Night only if the core case is done and green by about Nov 4. Record whatever Wadood decides in `docs/decisions.md`.

## P0: fix before building further (correctness and safety; all small)

**Engine**
- **E1. Objections accept a superset of evidence** (`Engine/game/ObjectionJudge.ts:9-11`). Offering all 21 known items breaks every lie with no pips lost. Require the presented evidence to be exactly a listed breaker (the UI drags one item). Add a test.
- **E2. Actions against an absent (lawyered) suspect still work** (`Engine/game/Reducer.ts:88-125`). Reject Object, Believe and Reveal while the suspect is out.
- **E3. Vale's layer-1 lie is missing valid breakers** (`Content/HeroCaseHarlow1041.ts:116`). The voicemail alone and Okafor's statement alone both contradict "already dead" but are overruled and cost a pip. Add them as breakers, with a regression test.
- **E4. Inspection is free, so inspecting everything solves the case at 0 minutes with a 3/3 rating** (`Scoring.ts:9`; all 250 "correct" fuzz players did this). Make object memories cost night-minutes (suggestion: 10 each, or a "three wake-ups" budget from the round-3 design), and rebase the Holmes rating on the solver's minimum route under real costs. Record the choice.

**AI safety**
- **A1. Lie stance leaks into the prompt** (`Content/HeroCaseHarlow1041.ts:134` → `Engine/perf/FactSheetBuilder.ts:9`; `Engine/case/StatementBuilder.ts:29-33`). Raw statement IDs like `a:C_S2_BASELINE_LIE` reach Vale's prompt and schema. Generated topics `baseline_lie`/`secret` and cover lines like "X denies the concealed forgery" name the secret. Fix:
  - use opaque reference IDs and neutral topic names;
  - write cover lines that never name the secret;
  - add a regression test asserting prompt content holds no stance words.
- **A2. The validator misses common confession, lie and meta wording, plus Unicode tricks** (`Engine/perf/LineValidator.ts:76-90`). These all pass today: "I'm the killer", "I've been lying", "My instructions…", full-width digits, "21h15", "elevenish", a Cyrillic "Ѕtudy", zero-width spaces. Fix:
  - expand contractions;
  - NFKC-normalize and strip invisible characters before checking, and speak the normalized text;
  - add spoken-time forms;
  - add every probe line from the AI review as a test.
- **A3. A line can deny the claim it cites, or invent facts.** "I was never in the Kitchen…", "My husband was with me…" and "Edmund was still alive at 22:30" all pass. Add a negation/polarity check against the cited claim, and an uncited-person/victim-state check.
- **A4. The reducer trusts the caller-supplied mode on `LineSpoken`** (`Engine/game/Reducer.ts:170-175`): a "broken" line is accepted at layer 0. Derive the mode from engine state.

**Hygiene**
- Fix the 2 `tsc` errors and add a `typecheck` script.
- **Track** the four git-lfs hooks in `.githooks/` (don't delete them: `pre-push` uploads the LFS assets).
- Update PROGRESS and the handoff with the corrected status above.

## P1: build these with C5 (needed for the demo)

- **L1. One coordinate frame.** The hero case puts the Kitchen at `[120,0,45]` (`HeroCaseHarlow1041.ts:7-11`); the `wadood-room` fixture used by the scene puts it at `[180,0,-250]` (`RoomFixtures.ts:15-18`). Five virtual props have no scene object, and no code maps case objects to scene objects. Fix:
  - add a room-binding component with a LEAF check;
  - create the virtual props;
  - move the zone plaques and anything needed on device **out of** the editor-only `PreviewRoom`.
- **A5. Gemini request** (`RoomscriptLlmClient.ts:26-28`): set `thinkingConfig` with budget 0, a real `systemInstruction` (stop flattening the system prompt into the user turn) and `maxOutputTokens`. Then measure 20 live answers. If it's still over budget, use cache-first chips with live answers only for free questions (the A5 plan).
- **A6. OpenAI fallback.** No gpt-4o-mini fallback exists, and the strict schema sends `minLength`/`maxLength`/`uniqueItems`, which strict mode likely rejects (*suspected*). Move request shaping and error mapping into `Engine/ai/` with tests, add an OpenAI schema projection, and verify with one live call.
- **A7. Audio.**
  - Synthesize sentences in parallel (today there's about a 2.2 s gap between them).
  - Make the splitter abbreviation-safe ("Dr.", "Mrs.", "10.30 p.m.").
  - Pre-synthesize fillers and chip lines.
  - Give each suspect their own voice (the TTS default is `onyx`, but the content gives Vale `coral`).
  - The 6.5 s fallback covers text only; budget for the audio too.
- **A8. Scheduler.** Reserve a slot for live questions (pre-empted background work holds the slot today), and cap the rate-limit cooldown below the answer budget (it's 8 s today).
- **C5 controller,** per the plan. Decide whether a free question's topic is locked before the model call, so the claim card and the spoken line can't disagree. Fall back to offline mode on `unauthenticated`.
- **Staging pass** (design 03 §0 and §6):
  - the HUD on the crate lid instead of three large panels (today they cover about 87% × 90% of the view);
  - compact chips and verbs;
  - the suspect at 1.3–2.0 m (Vale is 3.5 m away at 30° today);
  - subtitles at the speaker;
  - a brighter, on-palette crate (dark wood is invisible on an additive display);
  - plaque text at 1.0–1.5° tall.
- **Lens robustness:**
  - make engine initialization in `RoomscriptSuspectActor.ts:31` lazy (it calls `snapshot()` before init could happen);
  - stop the crate's update loop once the lid is open;
  - header contracts, `console.*` instead of `print`, `@hint` on every input, and `Button.size` set in `onInitialized` (`RoomscriptPanelUI.ts:55`).

## Generation and verification

Source inventory: `Tooling/audio/run10-script.json`. Wording command: `node Tooling/audio/run10-voices.mjs --check`. It checks every new line and the retained next-layer lines above against the forbidden-word list in the redesign, checks that each new Wren line ends with a question mark, and checks that this document contains the exact text before a paid request.

Generation uses the existing selected voices in `Tooling/audio/cast.json`, ElevenLabs `eleven_v3`, and timestamped responses. Narrator uses calm delivery; Wren uses a whisper. Normalization changes level and encoding only, preserving the timestamp timeline. Exported clips are mono 24 kHz MP3, with character alignment and bounded playback windows. All raw and staged files stay under `Tooling/audio/out/run10`; the worker ledger stays under `Tooling/audio` until merged into the shared ledger by the main agent.

Preview verification remains mandatory: matching subtitles, zero overlapping voices, and no unfinished line except case change or ending. File/metadata checks alone do not establish that result.

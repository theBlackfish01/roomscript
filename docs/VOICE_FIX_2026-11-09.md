Source backups stay in ignored `Tooling/audio/out/preview-originals/`. The idempotent script refuses to silently re-encode a changed file.
- Both speech players previously accepted a caption/manifest endpoint or decoder position as completion and immediately called `stop(false)`. The actual N10_OPEN_2 source is longer than its manifest endpoint. Completion now follows native playback, captures the finish counter before `play`, and allows 250 ms for native output to drain before advancing. A latched Preview EOF requires both the **native full-file duration plus buffer time** and the native EOF position; metadata endpoints alone never authorize stopping.
- Live TTS requests WAV rather than compressed MP3, retaining the existing admission checks and subtitle fallback. No paid live request was made in this repair.
- No game facts, line selection, case logic, or interaction design changed. Existing queued item observations continue to use the one speech arbiter.

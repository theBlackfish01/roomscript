# Original edit graphics

Generated by `Tooling/art/scripts/motion.mjs`, with the project's original vector glyphs and line art. These are **motion graphics, not gameplay captures**. They contain no audio.

| Clip | Duration | Format |
|---|---:|---|
| Title.mp4 | 4 s | 1920 x 1080, 30 fps, H.264 |
| Objection.mp4 | 3 s | 1920 x 1080, 30 fps, H.264 |
| EndCard.mp4 | 4 s | 1920 x 1080, 30 fps, H.264 |
| UnderTheHood.mp4 | 5 s | 1920 x 1080, 30 fps, H.264 |

All four decode cleanly through ffmpeg. Hashes and byte counts are in `manifest.json`; reviewed frames are in `docs/captures/2026-11-04-art-motion-contact.png`. The title/ending cards use an opaque dark background; alpha WebM variants are not included. Source PNG frames are regenerable and ignored under `Tooling/art/out/motion/`.

Original project code/art is MIT. Hero lettering is an original monoline alphabet. Other text is rasterized from the installed Windows Courier New; no font file is distributed. Local ffmpeg is a build tool and is not distributed.

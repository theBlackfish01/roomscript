# Run 8 engine presentation modules

These modules are pure and deterministic. They read `CaseGraph` and `GameState` and never write to them. The tests are the `tests/game/run8-*.test.ts` files.

| Module | Main exports | Available | Built from |
|---|---|---|---|
| `Engine/game/EvidenceWeb.ts` | `evidenceWeb(graph, state, {viewer?})`, `convergence(graph, state, {viewer?})`, `webNode`, `webName` | `evidenceWeb`: always (empty at start). `convergence`: only after a `correct` or `wrong` verdict; `null` before that and at timeout, the same gate as `reconstruction()`. | Threads come only from engine events: `evidence` (proof: facts proved by collected evidence), `objectionCorrect` (the liar to the breaker), `argumentSupported` (the support to the deduction subject, and only when that support names the subject), `refuted` (the refuter to the cleared card, when the fact is known) and admitted testimony (statements reached by a correct objection or cited in one or in a deduction). Links use only facts in `knowledge.factIds`. `WebThread.evidence` (optional) is the evidence that backs the thread. |
| `Engine/game/ObjectReplay.ts` | `objectReplay(graph, state, objectId, {evidence?, merge?})`, `objectReplays`, `collectedObjectEvidence` | Only after that object's evidence has been collected. | By default, one memory: the murder-slot memory if there is one, else the first timed memory, else the first. `merge: true` also brings in other collected memories from the same slot. A `touched` fact puts a person at the object only if a known `at` fact places them in that zone at that slot. `pose: "absent"` with `suspect: null` means this memory records no person; it does not mean the zone was empty. An untimed memory has the slot `"earlier"`. A figure's `suspect` can be the victim id. |
| `Engine/game/MorningEdition.ts` | `morningEdition`, `fitText`, `HEADLINE_MAX = 48`, `SUBHEAD_MAX = 70` | Only once there is a verdict. | A correct verdict names the accused (who is the culprit) and the method. A wrong verdict names only the accused, never the true culprit. Timeout gives "HARLOW CASE GOES COLD". The columns are counts from the events, notebook, arguments and clock. |
| `Engine/game/FrozenTableau.ts` | `frozenTableau`, `TABLEAU_LIFT_CM` | Only when `reconstructionBeats` has a freeze beat (a correct or wrong verdict). | Figure positions are copied exactly from the freeze beat's positions; no new placement maths. The culprit gets `holding = envelope.what` and a pose taken from the weapon type. `suspended` holds objects in the murder zone that a true murder-slot victim fact names, excluding the weapon. In the hero case that is only the mug, raised 18 cm. |
| `Engine/game/Fingerprints.ts` | `dustableObjects`, `dustingAction`, `DUSTABLE_TYPES` | Always. | Objects are picked by type (cup, then screen, then blunt) and by having non-latent evidence; at most two. The hero case gives `["O9", "O12"]`. `dustingAction` is exactly `PinchObject`. |
| `Engine/perf/CaseBoardLayout.ts` | `caseBoardLayout(graph, state, {width?, height?, viewer?})`, `boardLabel`, `BOARD_LABEL_MAX` | Always. | Items are rectangles given by their centre, with the origin at the board centre and +y up. WHO, WHERE and WITH WHAT rows sit on the left; photos sit on the right, below a stamp slot. Item ids are `who:` / `where:` / `what:` / `photo:<evidence>` / `stamp`. The stamp appears only once there is a verdict. Strings are web threads mapped onto board items. The victim has no card, so threads to the victim are dropped. |

## Truth-safety caveats

- `convergence` and `frozenTableau` reveal the sealed envelope on a **wrong** verdict too. That matches `reconstruction()`. Do not show them at timeout. They return `null` there anyway, but a timeout followed by a final accusation does unlock them.
- Testimony threads appear only for proved or cited statements. Do not add "heard but unproved" claims to the web: a missing thread would hint that the claim is a cover.
- In Clue Night, pass `{viewer: playerId}` to `evidenceWeb` and `caseBoardLayout`. Refutations are private, and without a viewer every refutation is shown.
- `dustableObjects` reveals that an object holds evidence, much as a hunch would. It does not reveal whom the evidence is about.
- Wrong-verdict newspaper copy implies that the charge was wrong; the verdict already says so.

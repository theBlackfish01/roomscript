# A7 scripted player gate

`Assets/Scripts/RoomscriptNaivePlayerLeafScenario.ts` was published and byte-checked after recovery 3. It must run in a freshly started Preset Preview. Main registers it as `roomscript-naive-player`; this lane does not use Lens tools. The scenario includes opening the crate and waits for the real ending. No `enterCase`, direct UI event invocation, engine dispatch or sealed-envelope lookup is used. Preview's large suspect target is the supported substitute for walking to an actor.

Every pinch, question-page change, carried-slip drag and seal hold increments `NAIVE_ACTION`. A forty-first action fails before execution. `NAIVE_PLAYER_CHECK` reports the exact count, opening-to-first-answer seconds, proof count and game minutes. First-answer timing is measured rather than silently equated with the thirty-second product target. The final accusation comes only from the sole hypothesis returned by `solvePlayerKnowledge` after collecting evidence. This is an automated accessibility regression, not a naive human user study.

The test asks Vale about the murder time, inspects the kettle, selects the displayed cold-kettle memory from the actual wallet and carries the statement to it. It then follows a fixed tour of visible marked objects (lamp, recorder, cable, door, window, and the four remaining possible weapons), files the known deductions and holds the verdict seal. Its target selection never calls `minimumCostRoute` or reads the envelope. The semantic text match for the kettle uses the displayed observed evidence, not a hidden breaker list.

Pure-engine validation: `node node_modules/tsx/dist/cli.mjs scripts/run7-naive-route.ts` from Tooling passes with a unique public hypothesis, four deductions and a correct verdict at 105 game minutes. It verifies the authored route's sufficiency, not physical UI behavior. Lens compilation and the actual interaction count remain pending main's MCP run.

Closing regression scenarios retain their previous assertions and now wait up to thirty-five seconds for the roughly twenty-nine-second reconstruction before checking the ending. This is a bounded presentation wait, not a changed game clock.
